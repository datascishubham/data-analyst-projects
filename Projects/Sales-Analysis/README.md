# Sales Analysis | SQL, Python, Power BI & Excel

## Project Overview

This project analyzes sales data to evaluate sales performance, profitability, order trends, customer segments, regions, and product performance.

## Tools & Technologies

- SQL
- Python
- Power BI
- Excel

## Analysis Performed

### SQL
- Data aggregation
- Joins
- Window functions
- Sales and profit analysis
- Top products and regions
- Customer analysis

### Python
- Data cleaning
- Exploratory Data Analysis (EDA)
- Data analysis
- Data visualization

### Power BI Dashboard

The interactive dashboard tracks:

- Sales
- Profit
- Number of Orders
- Quantity
- Profit Margin
- YoY Growth
- Monthly Sales Trend
- Sales by Segment
- Sales by Region
- Sales by Category
- Top Products


## Key Insights

- Analyzed sales performance across different segments, regions, and categories.
- Identified top-performing products based on sales and profit.
- Evaluated yearly and monthly sales trends.
- Compared sales and profitability to understand business performance.
